# deck.json の書式

マニュアルのスライドと、動画のナレーションを1つのファイルで管理する。
`build_deck.js` がスライドを作り、`make_video.py` が同じファイルの `say` を読み上げる。
完成した見本は `examples/wpforms-new-form/deck.json`（24枚）。新しく作るときはこれをコピーして書き換えるのが早い。

## 全体

```json
{
  "title": "〇〇 操作マニュアル",          // 表紙のタイトル
  "subtitle": "…から…まで",               // 表紙の副題
  "footnote": "〇〇 Pro 対応",            // 表紙の下の小さい文字（省略可）
  "output": "〇〇操作マニュアル.pptx",     // 書き出すファイル名（deck.json からの相対パス）
  "shotsDir": "shots",                    // スクリーンショットのフォルダ
  "rects": "rects.json",                  // 撮影時に記録した部品の位置
  "speak": { "WPForms": "ダブリューピーフォームズ" },  // 読み上げだけの言い換え（字幕はそのまま）
  "colors": { "orange": "E2652B" },       // 色を変えたいときだけ（# なし6桁）
  "slides": [ … ]
}
```

## スライドの種類

すべてのスライドに `say` を付けられる（動画用、後述）。

| type | 用途 | 主な項目 |
|---|---|---|
| `cover` | 表紙 | 全体の title/subtitle/footnote を使う |
| `flow` | 全体の流れ（大きいカード） | `title`, `cards: [[見出し, 説明], …]`, `note` |
| `section` | 章の扉 | `no`, `title`, `sub`, `section`（PowerPoint のセクション名） |
| `shot` | 画面1枚＋右に手順 | `title`, `shot`, `crop`, `marks`, `steps`, `note`, `extra` |
| `pair` | 画面2枚を左右に並べる（操作の前後） | `title`, `shots: [{shot, marks}, …]`, `steps`（横並び）, `note` |
| `banner` | 横長の画面＋下にカード | `title`, `shot`（高さ300で撮った画面）, `cards`, `note` |
| `cards` | 画面なしのまとめ（大きいカード） | `title`, `cards`, `note` |
| `table` | 表 | `title`, `header`, `rows`, `note` |
| `place` | サイトでの表示場所（公開側の画面＋表示されるページ・位置・URL） | `title`, `shot`, `crop`, `pages`, `position`, `urls`, `urlLabel`, `note` |

`cover` `section` 以外のスライドには `where` を付けられる。タイトルの下に「この編集機能があるページ：〇〇」と小さく表示する（例 `"where": "「新卒採用」「中途採用」"`）。

### shot の項目

- `shot`: `shots/` 内のファイル名（.png なし）。撮影は 1440×900、2倍解像度の前提。
- `crop`: `[x, y, w, h]`（画面座標）。指定すると切り抜いて大きく見せる。縦長に切り抜くと、画面を左に高さ優先で置き、手順を右に広く並べる（ログイン画面など）。
- `marks`: 赤枠と番号。並び順が番号になり、`steps` の順と対応する。
  - `"撮影名.部品名"`: rects.json に記録した位置（例 `"n01_forms.menu"`）。別の撮影の位置も使える。
  - `{ "box": [x, y, w, h] }`: 画面座標を直接書く（大きな範囲を囲むときなど）。
- `steps`: `[[見出し, 説明], …]`。説明は空文字でもよい。
- `note`: `{ "text": "…", "kind": "warn" }`。`kind` を省くと「ポイント」（オレンジ）、`warn` は「注意」（赤）。
- `extra`: 手順の下に置く補足カード。`{ "head": "…", "lines": ["…", "…"], "accentLast": true }`。

### place の項目

- `shot` / `crop` / `marks`: shot と同じ。公開側のページを撮った画像を使う。赤枠は無くてもよい。
- `pages`: 表示されるページ名の配列。
- `position`: ページのどこに表示されるか（例「募集要項の表の「お問い合わせ先」の欄」）。
- `urls`: URL の配列。`urlLabel` で見出しを変えられる（例「URL（例：トップページ）」）。

```json
{ "type": "place", "title": "サイトでの表示場所：採用の問い合わせ先", "shot": "f03_contact",
  "pages": ["募集要項（新卒採用）", "募集要項（中途採用）"],
  "position": "募集要項の表の「お問い合わせ先」の欄",
  "urls": ["https://example.jp/yokou-1/", "https://example.jp/yokou-2/"] }
```

### say（動画のナレーション）

```json
"say": {
  "intro": ["全体表示のまま読む文", "…"],
  "steps": [["赤枠1にズームして読む文", "…"], ["赤枠2で読む文"]],
  "zoom": [[9.6, 1.0, 3.6, 2.0]]
}
```

- 1文ごとに字幕が切り替わる。字幕が2行を超えないよう、1文は40字程度までにする。
- `steps` の n 番目は赤枠 n にズームする。赤枠が無いスライド（banner など）で寄せたい範囲があれば `zoom` にスライド上の位置（インチ、16:9 は 13.33×7.5）を書く。
- 英字・記号は読み上げで崩れやすい。字幕はそのままにして、全体の `speak` に読み方を書く（`/wp-admin/` → 「スラッシュ、ダブリューピー、アドミン、スラッシュ」など）。
- 書き言葉の「1行」「4つ」や、人名・地名のように読みが割れる語も `speak` で直す。

## 文章の決まり

言い切り・「クリック」「切り替え」などの言葉・表示場所の書き方は `writing-guide.md` に従う。書いたら `scripts/check_text.py deck.json` で点検する。

## 文字量の目安（はみ出し防止）

- `shot` の手順の説明：1項目 40 字まで（右側の幅 3.6 インチで2〜3行）。
- `note`：右側に置く場合は 50 字まで。全幅（flow/table/cards/pair）は 70 字まで。
- 行頭に「。」「、」だけが残る折り返しは見苦しいので、出たら語順を変えるか少し削る。
