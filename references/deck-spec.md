# deck.json の書式

マニュアルのスライドと、動画のナレーションを1つのファイルで管理する。
`build_deck.js` がスライドを作り、`make_video.py` が同じファイルの `say` を読み上げる。
新しく作るときは、いちばん下の「骨組み」をコピーして書き換える。骨組みの文章は伏せ字（〇〇）にしてあるので、writing-guide.md の決まりで、そのサイトの画面と作業に合わせて書く。スライドの順番や枚数も、そのサイトの作業に合わせて決める。

## 全体

```json
{
  "title": "〇〇 操作マニュアル",          // 表紙のタイトル
  "subtitle": "…から…まで",               // 表紙の副題
  "footnote": "〇〇 Pro 対応",            // 表紙の下の小さい文字（省略可）
  "output": "〇〇操作マニュアル.pptx",     // 書き出すファイル名（deck.json からの相対パス）
  "shotsDir": "shots",                    // スクリーンショットのフォルダ
  "rects": "rects.json",                  // 撮影時に記録した部品の位置
  "speak": { "WPForms": "ダブリューピーフォームズ" },  // 読み上げだけの言い換え（字幕はそのまま）
  "logo": "logo.png",                     // 白い背景用のロゴ。全ページの右上に背景なしで置く（省略可）。白い背景が塗られた画像なら白を透明にする
  "logoDark": "logo_white.png",           // 濃い背景用のロゴ。表紙と章の扉の右上に置く（省略可。無ければ logo の黒・灰色の文字を白にした版を自動で作る。false で置かない）
  "cred": "cred.json",                    // 文中の {{editor.user}} {{editor.pass}} を差し込むログイン情報（既定 cred.json）
  "coverImage": "cover.jpg",              // 表紙と章の扉の背景にする写真（省略可）。省略するとサイトの画面をぼかしたもの（design.json の bg）。false で塗りつぶし
  "design": "design.json",                // site_design.js が書き出した配色など（既定は design.json。false で使わない）
  "colors": { "orange": "E2652B" },       // 色を手で決めたいときだけ（# なし6桁）。design.json より優先
  "font": "Meiryo",                       // 書体を手で決めたいときだけ。design.json より優先
  "slides": [ … ]
}
```

### 見た目の決まり方

1. 既定の見た目（紺とオレンジ）
2. `design.json` があれば、サイトから読み取った値で上書き
3. deck.json の `colors` / `font` があれば、さらにそれで上書き

`colors` で変えられる色：

| 名前 | 使う場所 | design.json の対応 |
|---|---|---|
| `orange` | メインの色。手順の番号、flow カードの番号、「ポイント」の文字 | `primary` |
| `navy` | 表紙・章の扉の背景、タイトルの文字 | `dark` |
| `mark` | 画面上のクリック場所の目印（枠と番号） | `mark`（メインの色が赤系のときだけ青になる） |
| `red` | 「注意」の文字 | （変えない） |
| `peach` | 「ポイント」の枠 | メインの色を薄くした色（赤系のときはグレー） |
| `subtitle` | 表紙の副題、章の番号 | メインの色を薄くした色 |

角の丸さは design.json の `radius`（インチ。0 なら四角）で決まる。

## スライドの種類

すべてのスライドに `say` を付けられる（動画用、後述）。

| type | 用途 | 主な項目 |
|---|---|---|
| `cover` | 表紙 | 全体の title/subtitle/footnote を使う |
| `toc` | 目次（章と主な項目、右端にページ番号） | `title`, `rows`（省略で自動）, `note` |
| `compare` | 管理画面とサイトの表示を左右に並べ、同じ番号で対応を示す | `title`, `labels`, `shots: [管理画面, サイト]`, `steps`, `note`, `where` |
| `flow` | 全体の流れ（「01 ── 見出し　説明」の縦の並び。目次のように見せる） | `title`, `cards: [[見出し, 説明], …]`, `note` |
| `section` | 章の扉 | `no`, `title`, `sub`, `section`（PowerPoint のセクション名） |
| `shot` | 画面1枚＋右に手順 | `title`, `shot`, `crop`, `marks`, `steps`, `note`, `extra` |
| `pair` | 画面2枚を左右に並べる（操作の前後） | `title`, `shots: [{shot, marks}, …]`, `steps`（横並び）, `note` |
| `banner` | 横長の画面＋下に横並びの手順 | `title`, `shot`（高さ300で撮った画面、または `crop` で横長に切り抜く）, `crop`, `cards`, `note` |
| `cards` | 画面なしのまとめ（flow と同じ縦の並び） | `title`, `cards`, `note` |
| `table` | 表 | `title`, `header`, `rows`, `note` |
| `place` | サイトでの表示場所（公開側の画面＋表示されるページ・位置・URL） | `title`, `shot`, `crop`, `pages`, `position`, `urls`, `urlLabel`, `note` |

`cover` `section` 以外のスライドには `where` を付けられる。タイトルの下に「この編集機能があるページ：〇〇」と小さく表示する（例 `"where": "「新卒採用」「中途採用」"`）。

### toc の項目（目次）

表紙の次に置く。「このマニュアルで説明すること」のようなページの代わりに使う。

- `rows` を省くと自動で作る：章の扉（`section`）が番号つきの行（説明は `tocSub` か `sub`）、`"toc": true`（または目次に出す名前の文字列）を付けたスライドが字下げの行になる。ページ番号はスライドの順番から入る。
- 手で書くとき：`[[章番号 or "", 見出し, 説明, ページ], …]`。ページに数字ではなく文字を書くと、その文字で始まるタイトルのスライドのページ番号になる（例 `"画像を変える①"`）。

```json
{ "type": "toc", "title": "目次", "note": { "text": "どの画面も、最後に「更新」をクリックするまでサイトには反映されません。" } }
```

### compare の項目（管理画面とサイトの対応）

「どこを変えると、サイトのどこが変わるか」を見せる。左が管理画面、右がサイト。番号が同じものどうしが対応する。

- `labels`: 2つの見出し（既定 `["管理画面", "サイトでの表示"]`）。右は `"サイト：〇〇ページ"` のようにページ名を書く。
- `shots`: `[{ "shot", "crop", "marks" }, { "shot", "crop", "marks" }]`。2つの `marks` は同じ並び・同じ数にする。サイトに出ない欄は、右の marks のその位置を `null` にする（番号は進む）。
- `steps`: `[[見出し, 説明], …]`。下に横に並ぶ。4つまでが読みやすい（5つ以上なら2枚に分ける）。
- サイト側の画像は `L.siteShot()` で撮る。枠は部品の位置（rects.json）か `box` で付ける。

```json
{ "type": "compare", "title": "タブ④「リード・コンセプト」", "where": "「〇〇」",
  "labels": ["管理画面", "サイト：〇〇ページ"],
  "shots": [
    { "shot": "p_tab04", "crop": [172, 300, 958, 600], "marks": ["p_tab04.lead", "p_tab04.ctitle", "p_tab04.badge"] },
    { "shot": "f_lead", "crop": [220, 70, 1000, 440], "marks": ["f_lead.lead", { "rect": "f_lead.ctitle", "pos": "L" }, null] } ],
  "steps": [["リード文（3行）", "1行ずつ別々の欄に"], ["コンセプト見出し", ""], ["タブのバッジ", "現在は表示なし"]] }
```

### marks の共通の決まり（番号の位置）

- 番号の丸は、ボタンや文字を隠さないよう枠の外に自動で置く（小さい枠は上→下→右→左、大きい枠は左→上→右→下。画面の外の余白を優先）。
- 枠どうしが重なると、重なりの真ん中で両方を少し縮める。
- 自動の位置が悪いときは、その目印を `{ "rect": "撮影名.部品名", "pos": "R" }` や `{ "box": [...], "pos": "B" }` にする（`L` 左・`A` 上・`R` 右・`B` 下）。
- 1つの欄を囲むのに、ラベルと入力欄など複数の部品をまとめたいときは、部品の位置を合わせた `box` を作る（左右上下を数 px 内側に縮めると、隣の枠と重なりにくい）。

### shot の項目

- `shot`: `shots/` 内のファイル名（.png なし）。撮影は 1440×900、2倍解像度の前提。
- `crop`: `[x, y, w, h]`（画面座標）。指定すると切り抜いて大きく見せる。縦長に切り抜くと、画面を左に高さ優先で置き、手順を右に広く並べる（ログイン画面など）。
- `marks`: 赤枠と番号。並び順が番号になり、`steps` の順と対応する。
  - `"撮影名.部品名"`: rects.json に記録した位置（例 `"n01_forms.menu"`）。別の撮影の位置も使える。
  - `{ "box": [x, y, w, h] }`: 画面座標を直接書く（大きな範囲を囲むときなど）。
- `steps`: `[[見出し, 説明], …]`。説明は空文字でもよい。
- `note`: `{ "text": "…", "kind": "warn" }`。`kind` を省くと「ポイント」（オレンジ）、`warn` は「注意」（赤）。
- `extra`: 手順の下に置く補足カード。`{ "head": "…", "lines": ["…", "…"], "accentLast": true }`。

### place の項目

- `shot` / `crop` / `marks`: shot と同じ。公開側のページを撮った画像を使う。赤枠は無くてもよい。
- `pages`: 表示されるページ名の配列。
- `position`: ページのどこに表示されるか（例「募集要項の表の「お問い合わせ先」の欄」）。
- `urls`: URL の配列。`urlLabel` で見出しを変えられる（例「URL（例：トップページ）」）。

```json
{ "type": "place", "title": "サイトでの表示場所：採用の問い合わせ先", "shot": "f03_contact",
  "pages": ["募集要項（新卒採用）", "募集要項（中途採用）"],
  "position": "募集要項の表の「お問い合わせ先」の欄",
  "urls": ["https://example.jp/yokou-1/", "https://example.jp/yokou-2/"] }
```

### say（動画のナレーション）

```json
"say": {
  "intro": ["全体表示のまま読む文", "…"],
  "steps": [["赤枠1にズームして読む文", "…"], ["赤枠2で読む文"]],
  "zoom": [[9.6, 1.0, 3.6, 2.0]]
}
```

- 1文ごとに字幕が切り替わる。字幕が2行を超えないよう、1文は40字程度までにする。
- `steps` の n 番目は赤枠 n にズームする。赤枠が無いスライド（banner など）で寄せたい範囲があれば `zoom` にスライド上の位置（インチ、16:9 は 13.33×7.5）を書く。
- 英字・記号は読み上げで崩れやすい。字幕はそのままにして、全体の `speak` に読み方を書く（`/wp-admin/` → 「スラッシュ、ダブリューピー、アドミン、スラッシュ」など）。
- 書き言葉の「1行」「4つ」や、人名・地名のように読みが割れる語も `speak` で直す。

## 文章の決まり

言い切り・「クリック」「切り替え」などの言葉・表示場所の書き方は `writing-guide.md` に従う。書いたら `scripts/check_text.py deck.json` で点検する。

## 文字量の目安（はみ出し防止）

- `shot` の手順の説明：1項目 40 字まで（右側の幅 3.6 インチで2〜3行）。
- `note`：右側に置く場合は 50 字まで。全幅（flow/table/cards/pair）は 70 字まで。
- 改行は build_deck.js が入れる（文節の切れ目で改行し、行頭に「。」「、」を置かない）。deck.json の文章に改行を入れる必要はない。
- それでも1行に1〜2文字だけ残るような折り返しが出たら、語順を変えるか少し削る。

## ページの見た目（build_deck.js が決めること）

人が作った資料に近づけるため、次のように組む。deck.json で指定する必要はない。

- 中身のページ：左上に小さな色の四角、タイトルの上に今いる章の名前（`section` の `section` か `title`）、タイトルの「」の中だけメインの色。ロゴは右上（タイトルの幅はロゴの分だけ狭くなる）。
- 表紙と章の扉：ロゴは右上（濃い背景用）。
- 画面スライド（shot）：画面が低いときは、画面と右の手順をまとめて縦の真ん中に置く（下半分が空かないように）。`extra` があるときは上から置く。
- 表紙と章の扉：サイトの画面（または `coverImage`）をぼかした背景に、濃い色を半透明で重ねる。扉は「02 ───」のように番号と細い線を置く。
- flow / cards：カードを横に並べず、番号・細い線・見出し・説明を縦に並べる。

## 骨組み（コピーして使う）

すべてのスライドの種類を1枚ずつ並べた書式の見本。文章は伏せ字なので、そのまま使わない。使わない種類のスライドは消し、必要な種類は何枚でも増やす。

```json
{
 "title": "〇〇 操作マニュアル",
 "subtitle": "〇〇から〇〇まで",
 "output": "〇〇操作マニュアル.pptx",
 "shotsDir": "shots",
 "rects": "rects.json",
 "logo": "logo.png",
 "speak": { "〇〇": "まるまる" },
 "slides": [
  { "type": "cover",
    "say": { "intro": ["〇〇の手順を説明します。"] } },
  { "type": "toc", "title": "目次",
    "note": { "text": "〇〇の場合は、〇〇してください。" } },
  { "type": "section", "no": 1, "title": "〇〇", "sub": "〇〇（〇〇、〇〇）", "section": "1. 〇〇" },
  { "type": "shot", "title": "〇〇する", "noWhere": true, "shot": "a01_login", "crop": [500, 20, 440, 600],
    "marks": ["a01_login.user", "a01_login.pass", "a01_login.submit"],
    "steps": [["〇〇を入力", "〇〇を入力します"], ["〇〇を入力", ""], ["「〇〇」をクリック", "〇〇が表示されます"]],
    "extra": { "head": "ログイン情報", "lines": ["URL：https://〇〇.jp/wp-admin/", "ユーザー名：{{editor.user}}", "パスワード：{{editor.pass}}"] } },
  { "type": "shot", "title": "〇〇を〇〇する", "where": "「〇〇」「〇〇」", "shot": "b02_edit",
    "marks": ["b02_edit.field", { "box": [100, 200, 600, 300] }],
    "steps": [["「〇〇」を入力", "〇〇の〇〇に表示されます"], ["「更新」をクリック", ""]],
    "note": { "kind": "warn", "text": "〇〇を変えると、〇〇されなくなります。" },
    "say": { "intro": ["〇〇の画面です。"], "steps": [["〇〇を入力します。"], ["更新をクリックします。"]] } },
  { "type": "compare", "title": "〇〇を編集する", "where": "「〇〇」", "toc": true,
    "labels": ["管理画面", "サイト：〇〇ページ"],
    "shots": [{ "shot": "b03_tab", "crop": [172, 300, 958, 600], "marks": ["b03_tab.a", "b03_tab.b"] },
              { "shot": "f03_page", "crop": [200, 0, 1040, 600], "marks": ["f03_page.a", null] }],
    "steps": [["〇〇", "〇〇に表示されます"], ["〇〇", "現在は表示なし"]] },
  { "type": "place", "title": "サイトでの表示場所：〇〇", "shot": "c03_front",
    "pages": ["〇〇", "〇〇"], "position": "〇〇の〇〇の欄", "urls": ["https://〇〇.jp/〇〇/"] },
  { "type": "pair", "title": "〇〇を〇〇する",
    "shots": [{ "shot": "d04_before", "marks": ["d04_before.x"] }, { "shot": "d05_after", "marks": ["d05_after.y", "d05_after.z"] }],
    "steps": [["〇〇を削除", "〇〇をクリックします"], ["〇〇をクリック", ""], ["「〇〇」を選択", "〇〇に〇〇されます"]] },
  { "type": "banner", "title": "〇〇して閉じる", "shot": "e06_top", "crop": [0, 0, 1440, 300],
    "cards": [["「〇〇」をクリック", "〇〇すると、〇〇は消えます"], ["〇〇を閉じる", ""]] },
  { "type": "table", "title": "〇〇の種類",
    "header": ["〇〇", "〇〇"], "rows": [["〇〇", "〇〇の入力"], ["〇〇", "〇〇の選択"]] },
  { "type": "cards", "title": "〇〇後、〇〇を行う",
    "cards": [["〇〇", "〇〇します"], ["〇〇", "〇〇を確認します"]] }
 ]
}
```
