# wp-manual-video

WordPressの管理画面を実際に操作・撮影し、初心者向けの操作マニュアル（PowerPoint / PDF）と、ナレーション・字幕付きの手順動画（MP4）を制作するためのAgent Skillです。

## 主な機能

- 編集者など、マニュアルの読者と同じ権限で操作画面を撮影
- スクリーンショットに操作箇所の赤枠・番号を追加
- 同一の `deck.json` からPowerPoint・PDF・動画を制作
- 公開側のどの場所に反映されるかを説明
- WordPress / WPForms / カスタム投稿 / 固定ページ / ACF などの操作説明に対応

## ファイル構成

- `SKILL.md` — 作業手順・実行ルール
- `references/` — 撮影・文章・スライド仕様
- `scripts/` — 撮影支援・資料・動画生成スクリプト
- `examples/wpforms-new-form/` — WPFormsを例にした構成ファイル

## 導入

Agent Skillsに対応する実行環境のスキルディレクトリに、このリポジトリの内容を `wp-manual-video` フォルダとして配置してください。対応する実行環境で `SKILL.md` を読み込み、記載の手順に従います。

ローカルのMacで実行する場合、Node.js v22、Python、Chrome系ブラウザ、PDF・動画生成のための外部ツールなどが必要です。依存関係とセットアップは `SKILL.md` と `scripts/setup.sh` を確認してください。環境により追加設定が必要です。

## セキュリティ上の注意

- `cred.json`、ログイン情報、APIキーをGitHubにコミットしないでください。
- 撮影した画面や作業成果物に顧客名、メールアドレスなどが含まれていないか確認してください。
- 本番サイトのテストデータ作成や削除は、作業前に許可を得てください。
- サンプルの設定値は環境ごとに変更してください。
